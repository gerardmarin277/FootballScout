# ⚽ FootballScout

**Football Scouting & Player Analytics Platform**

FootballScout es una plataforma de análisis y scouting de fútbol desarrollada íntegramente en Python. Permite evaluar futbolistas, medir su compatibilidad con perfiles tácticos específicos y generar informes de scouting orientados a la toma de decisiones.

## 🏗️ Arquitectura V1 (MVP)

- **Language:** Python 3.10+
- **Database:** SQLite + SQLAlchemy 2.0 ORM
- **Architecture:** Clean Architecture / Modular Structure
- **Interface:** Command Line Interface (CLI)
